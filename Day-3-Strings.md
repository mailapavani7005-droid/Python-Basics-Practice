# Day 3 - Strings

## Topics Covered

### String

A string is a sequence of characters enclosed in single or double quotes.

### Indexing

Used to access a single character from a string.

### Slicing

Used to access multiple characters from a string.

### String Methods

* upper()
* lower()
* replace()
* split()
* len()

## Programs Practiced

* Print First Character
* Print Last Character
* String Slicing
* Convert to Uppercase
* Replace Characters
* Split a Sentence
* Find String Length

## What I Learned

I learned how to access and manipulate text using strings and string methods.
