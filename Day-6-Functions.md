# Day 6 - Functions

## Topics Covered

### Functions

Functions are reusable blocks of code.

### Parameters

Values passed to a function.

### Return Statement

Used to return a result from a function.

### Local Variables

Variables created inside a function.

### Global Variables

Variables created outside a function.

### Lambda Functions

Small one-line functions.

## Programs Practiced

* Greeting Function
* Addition Function
* Square Function
* User Input Function
* Lambda Addition Program

## What I Learned

I learned how to create reusable code using functions and return values from functions.
