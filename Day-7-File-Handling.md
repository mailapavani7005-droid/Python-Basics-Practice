# Day 7 - File Handling

## Topics Covered

### open()

Used to open a file.

### read()

Used to read file content.

### write()

Used to write data into a file.

### append()

Used to add data to an existing file.

### close()

Used to close a file.

### with open()

Automatically closes the file after use.

## Programs Practiced

* Read File Data
* Write Data into a File
* Append Data to a File
* Read File Using with open()

## What I Learned

I learned how Python interacts with files to store, read, and update data.
